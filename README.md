# 🌤️ 등하교 날씨 브리핑 봇

매일 아침 07:30에 **등교(08시)~하교(22시)** 기상청 단기예보를 분석해서
**우산 지참 여부 · 추천 옷차림 · 일교차 겉옷 경고**를 메신저(Discord / 카카오톡)로 보내 줍니다.

```
☔ 오후 16시~18시 비 예보(최대 70%), 우산 꼭 챙기세요! ☔
👕 오늘 옷차림(최고 21℃): 긴팔티, 가디건, 후드티, 면바지
⚠️ 밤 하교 시간(22시)에 기온이 급락합니다! 입고 벗기 편한 겉옷(바람막이/가디건/집업)을 꼭 챙기세요.
```

## 1단계. 설치하고 바로 실행해 보기 (API 키 없어도 OK)

1. Python 3.9 이상 설치 (설치 시 **"Add Python to PATH"** 체크)
   > 💡 Windows에서 `python`을 입력했는데 아무 반응이 없거나 Microsoft Store가 열리면,
   > 아래 모든 명령에서 `python` 대신 **`py`** 를 쓰세요. (예: `py main.py --once`, `py -m pip install ...`)
2. 이 폴더에서 터미널(PowerShell)을 열고 라이브러리 설치
   ```bash
   python -m pip install -r requirements.txt
   ```
3. 설정 파일 만들기: `.env.example`을 복사해 `.env`로 이름 변경
   ```bash
   copy .env.example .env
   ```
4. 테스트 실행 (메신저로 보내지 않고 화면에만 출력)
   ```bash
   python main.py --once --dry-run
   ```
   API 키가 비어 있으면 자동으로 **가짜 데이터(Mock)** 로 실행되고, 메시지 제목에 `[테스트]`가 붙습니다.
   `.env`에서 `MOCK_SCENARIO=clear`로 바꾸면 "맑은 날" 메시지도 확인할 수 있어요.

## 2단계. 기상청 API 키 발급받기

1. [공공데이터포털](https://www.data.go.kr) 회원가입 / 로그인
2. 검색창에 **"기상청_단기예보 조회서비스"** 검색 → 오픈 API 탭 선택
3. **[활용신청]** 클릭 → 활용 목적(예: "개인 학습용 날씨 알림 봇") 입력 → 신청 (보통 자동 승인)
4. **마이페이지 > 데이터활용 > Open API > 활용신청 현황**에서 신청한 API 클릭
5. **일반 인증키(Decoding)** 값을 복사해 `.env`에 붙여넣기
   ```
   KMA_SERVICE_KEY=복사한키값
   ```
   > Encoding 키를 넣어도 자동 변환되니 걱정하지 마세요.
   > 발급 직후에는 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 날 수 있어요. **1~2시간 뒤** 다시 시도하세요.
6. 실제 데이터로 확인
   ```bash
   python weather_fetcher.py
   ```

### 우리 동네 격자 좌표(NX, NY) 설정

기상청은 위도/경도 대신 격자 좌표를 씁니다. 학교 위치의 위도/경도를 구글 지도에서 우클릭해 복사한 뒤:

```bash
python weather_fetcher.py --grid 37.5665 126.9780
```

출력된 `NX`, `NY` 값과 지역 이름을 `.env`에 넣으세요.

## 3단계. Discord Webhook 만들기

1. Discord에서 내 서버 만들기 (왼쪽 `+` 버튼 → "직접 만들기")
2. 알림 받을 채널 옆 ⚙️ **채널 편집 > 연동 > 웹후크 > 새 웹후크**
3. **웹후크 URL 복사** → `.env`에 붙여넣기
   ```
   DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/....
   ```
4. 실제 전송 테스트
   ```bash
   python main.py --once
   ```
5. 휴대폰에 Discord 앱을 설치하고 알림을 켜 두면 아침마다 푸시가 와요.

## 4단계. 매일 자동 실행

### 방법 A) 내 PC에서 켜두기

```bash
python main.py
```

창을 켜두면 매일 `BRIEFING_TIME`(기본 07:30, **PC 시계 기준**)에 전송합니다. PC가 꺼지거나 절전 모드면 동작하지 않아요.

### 방법 B) GitHub Actions (PC 꺼져 있어도 무료로 자동 실행) ⭐ 추천

1. [GitHub](https://github.com)에 새 저장소(Repository)를 만들고 이 폴더 파일을 모두 올립니다.
   (`.env`는 `.gitignore` 때문에 올라가지 않아요. **절대 직접 올리지 마세요.**)
2. 저장소 **Settings > Secrets and variables > Actions**
   - **Secrets** 탭 → `New repository secret`
     - `KMA_SERVICE_KEY` : 기상청 인증키
     - `DISCORD_WEBHOOK_URL` : Discord 웹후크 URL
   - **Variables** 탭 (선택) → `NX`, `NY`, `LOCATION_NAME`
3. **Actions** 탭 → `Daily Weather Briefing` → **Run workflow** 로 바로 테스트
4. 이후 매일 07:30(KST)에 자동 실행됩니다.

> ⚠️ 알아둘 점
> - GitHub 예약 실행은 서버 사정에 따라 **몇 분~수십 분 늦을 수 있습니다.** 늦는 게 싫으면 `daily_briefing.yml`의 cron을 `"15 22 * * *"`(07:15)로 앞당기세요.
> - 저장소에 **60일 동안 활동(커밋)이 없으면** 예약 실행이 자동으로 꺼집니다. Actions 탭에서 다시 켜면 돼요.

## 🌐 웹사이트로 보기 (메신저 없이)

같은 브리핑을 휴대폰 브라우저에서 바로 볼 수 있는 웹페이지입니다. 일반 날씨 앱처럼 시간별 날씨를 나열하는 대신 **학생의 하루(등교 → 수업 → 귀가)** 에 맞춰 보여 줘요.

### 🎒 학생 맞춤 화면

- **🏠 나는 몇 시에 집에 가요?** — `16시 정규 하교` · `18시 방과후` · `21시 학원` · `22시 야자` 중에 고르면 아래 내용이 전부 **8시 ~ 귀가 시간** 기준으로 다시 계산됩니다. (고른 값은 브라우저에 기억)
- **🚶 등굣길 · 귀갓길** — 두 길의 기온, 체감(쌀쌀해요/추워요…), 그때 입을 옷을 나란히 보여 주고, 낮보다 귀갓길이 많이 추우면 경고합니다.
- **🎒 가방 챙기기** — 우산, 입고 벗기 편한 겉옷, 핫팩(귀갓길 5° 이하), 물·손풍기(낮 28° 이상)를 체크리스트로.
- **👔 오늘 교복 코디** — 낮 최고 기온으로 하복/춘추복/동복을 추천하고, 등하굣길이 추우면 "가방에 겉옷 하나 더"를 알려 줍니다. 학원·주말용 사복 추천도 함께.
- **📅 오늘 내 하루** — 등교 · 점심시간 · 정규 수업 끝 · 학원 이동 · 귀가 때의 날씨. 지금 다음 일정엔 `다음` 표시가 붙어요.
- **🌡️ 기온 흐름** — 등교부터 귀가까지의 기온 그래프 (비 오는 시간은 파란 영역).
- 상단의 **자동 · 라이트 · 다크** 버튼으로 화면 테마를 고를 수 있어요.

> 판정 기준(강수확률 60%, 일교차 8°, 등하교 기온 차 6°)은 `analyzer.py` 값을 그대로 써서 Discord·카카오톡 브리핑과 같습니다.
> 메신저 브리핑과 '다른 지역 일교차' 목록은 귀가 22시 기준이에요.

### 📍 다른 지역 일교차 검색

페이지 아래쪽 **다른 지역 일교차** 카드에서 전국 43개 지역(울릉도·독도 포함)의 오늘 일교차를 비교하고 검색할 수 있습니다.

- **권역 버튼:** 전체 · 수도권 · 강원 · 충청 · 전라 · 경상 · 제주 중 하나를 누르면 그 권역만 보여 줍니다. 처음엔 지금 보는 지역의 권역이 열려요.
- **검색:** 도시 이름(`부산`, `울릉`), 시·도 이름(`경기`, `강원`), 초성(`ㅂㅅ`, `ㅈㅈ`) 모두 됩니다.
- **정렬:** 일교차 큰 순 / 가나다순
- **앱 아이콘 모양:** 휴대폰 홈 화면처럼 지역마다 둥근 아이콘 안에 일교차 숫자가 크게 보이고, 아래에 이름과 최저~최고 기온이 나옵니다.
  아이콘 색은 🟧 겉옷 필요(⚠) · 🟩 보통 · 🟦 일교차 작음(5° 미만)이고, 비 예보가 있으면 알림 배지처럼 ☔가 붙어요.
- **🔥 일교차 큰 곳:** 오늘 일교차가 가장 큰 3곳으로 바로 갈 수 있습니다.
- 지역을 누르면 그 지역의 전체 브리핑 페이지(`busan.html` 등)로 이동합니다. 맨 위 **📍 지역** 버튼으로 언제든 목록으로 갈 수 있어요.

지역을 추가하려면 [regions.py](regions.py)의 `REGIONS`에 `Region("slug", "이름", "시·도", 위도, 경도)` 한 줄을 넣으면 됩니다.
페이지를 만들 때 지역마다 기상청 API를 1번씩 호출하므로(현재 하루 약 43회), 개발계정 한도(하루 10,000회) 안에서 넉넉합니다.

### 방법 A) 내 PC에서 바로 보기

```bash
py web_page.py
```

`site/index.html`(기본 지역)과 지역별 페이지들이 만들어지면 `index.html`을 더블클릭해서 브라우저로 여세요. 전국 지역을 받아오느라 1분 정도 걸립니다.

접속할 때마다 최신 예보를 보고 싶으면 서버를 켭니다.

```bash
py -m uvicorn web_server:app --host 0.0.0.0 --port 8000
```

PC에서는 `http://localhost:8000`, 같은 와이파이에 연결된 휴대폰에서는 `http://<PC의 IP 주소>:8000`으로 접속합니다. (PC IP는 `ipconfig`의 IPv4 주소)

### 방법 B) GitHub Pages로 무료 웹사이트 만들기 ⭐ 추천

PC를 꺼 둬도 매일 05:30(KST)에 자동으로 갱신되는 웹사이트 주소가 생깁니다.

1. 4단계 방법 B처럼 저장소를 만들고 Secrets에 `KMA_SERVICE_KEY`를 등록합니다. (웹사이트만 쓸 거면 Discord URL은 없어도 됩니다)
2. 저장소 **Settings > Pages > Build and deployment > Source**를 **GitHub Actions**로 바꿉니다.
3. **Actions** 탭 → `Publish Weather Website` → **Run workflow**로 첫 배포를 합니다.
4. 완료되면 `https://<내 GitHub 아이디>.github.io/<저장소 이름>/` 주소로 접속할 수 있어요. 휴대폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

> ⚠️ 무료 계정은 **공개(Public) 저장소**에서만 GitHub Pages를 쓸 수 있습니다. 코드는 공개되지만 API 키는 Secrets에 있어서 노출되지 않아요.
> 웹사이트 주소를 아는 사람은 누구나 페이지를 볼 수 있습니다. (날씨 정보와 지역 이름만 표시됩니다)

## 5단계(선택). 카카오톡 오픈빌더 연동

카카오톡 채널에서 "날씨"나 "부산 날씨"처럼 말하면 그 지역 브리핑을 답장해 주는 방식입니다.
(오픈빌더 스킬은 **사용자가 먼저 말을 걸 때만** 응답할 수 있어서, 아침 자동 푸시는 Discord로 받는 걸 추천해요.)

### 이렇게 말하면 이렇게 답해요

| 보낸 말 | 답장 |
|---|---|
| `날씨`, `오늘 날씨 알려줘` | 기본 지역(.env의 `LOCATION_NAME`) 브리핑 |
| `부산 날씨`, `제주도 날씨 어때?`, `경기 수원 날씨` | 그 도시 브리핑 (웹사이트와 같은 43개 지역, `울릉 날씨`·`독도 날씨`도 가능) |
| `강원도 날씨`, `경남 날씨` | 시·도의 대표 도시 브리핑 (강원 → 춘천, 경남 → 창원 등) |
| `포천 날씨` (목록에 없는 곳) | "아직 지원하지 않는 지역" 안내 + 기본 지역 브리핑 |
| `지역 목록` | 물어볼 수 있는 전체 지역 이름 |

답장 아래에는 `부산 날씨`, `대구 날씨` 같은 **바로가기 버튼**이 붙어서 눌러 보기만 하면 돼요.

### 연결 방법

1. 서버 실행 (켜지자마자 전국 43개 지역 예보를 미리 받아 둡니다)
   ```bash
   py -m uvicorn kakao_server:app --host 0.0.0.0 --port 8000
   ```
2. 외부에서 접속 가능한 HTTPS 주소 필요 → 테스트는 [ngrok](https://ngrok.com) (`ngrok http 8000`), 상시 운영은 Render/Railway 같은 무료 호스팅
3. [카카오 비즈니스](https://business.kakao.com)에서 카카오톡 채널 생성 → [카카오 i 오픈빌더](https://chatbot.kakao.com)에서 봇 생성 후 채널 연결
4. **스킬 > 생성** → URL에 `https://<내주소>/kakao/briefing` 입력
5. **시나리오 > 블록 생성** → 봇 응답을 **스킬데이터**로 설정하고, 사용자 발화를 넉넉히 등록합니다.
   - 예: `날씨`, `오늘 날씨`, `우산 챙겨야 해?`, `부산 날씨`, `제주도 날씨 어때`, `강원도 날씨`, `대구 날씨 알려줘`, `지역 목록`
   - 오픈빌더가 비슷한 말도 같은 블록으로 연결해 주지만, 지역 이름이 들어간 예시를 여러 개 넣어 둘수록 잘 잡혀요.
   - 지역 이름은 서버가 직접 찾아내므로 엔티티(파라미터) 설정은 필요 없습니다.
6. 배포 후 카카오톡 채널에서 "부산 날씨" 입력

> 오픈빌더는 5초 안에 답이 없으면 실패로 처리합니다. 서버는 4초 안에 예보를 못 받으면
> "불러오는 중이에요, 잠시 후 다시 물어봐 주세요"라고 먼저 답하고, 조회는 계속해서 다음 질문엔 바로 답해요.

응답 JSON 예시:
